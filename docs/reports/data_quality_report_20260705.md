## 2. 质检规则

本轮已覆盖以下规则：

| 类别 | 规则 | 说明 |
|---|---|---|
| 分区完整性 | `missing_partition` | 检查交易日对应分区是否存在 |
| 主键唯一性 | `duplicate_key` | 检查 `ts_code + trade_date` 是否重复 |
| 必填字段 | `required_columns` | 检查表结构字段是否完整 |
| 行情正数校验 | `positive_price` / `positive_amount` | 检查价格、成交额、成交量是否为正 |
| OHLC 一致性 | `ohlc_relationship` | 检查 `high >= max(open, close)`、`low <= min(open, close)`、`high >= low` |
| 涨跌幅一致性 | `pct_chg_consistency` | 检查 `close / pre_close - 1` 与 `pct_chg` 是否一致 |
| 复权因子有效性 | `adjustment_factor_values` | 检查复权因子是否有效 |
| 复权因子覆盖率 | `adjustment_market_coverage` | 检查复权因子代码对行情代码的覆盖率 |
| 复权收益率跳变 | `adjusted_return_jump` | 用 `close * adj_factor` 计算后复权收盘价并检查收益率跳变 |

复权收益率跳变阈值：

| 市场 | 阈值 | 特殊处理 |
|---|---:|---|
| 股票 | `abs(return) > 35%` | 忽略 `.BJ` 北交所代码 |
| ETF | `abs(return) > 50%` | 无特殊排除 |

| `20260701` | 1 | 最新问题，`001331.SZ` 复权因子异常跳变 |

最新明确可疑点：

| ts_code | 日期 | close | pre_close | 实际 adj_factor | 按 pre_close 反推理论 adj_factor |
|---|---:|---:|---:|---:|---:|
| `001331.SZ` | `20260701` | 62.02 | 56.38 | 3.4848 | 2.4011 |

该记录中：

```text
20260630 close = 56.38
20260630 adj_factor = 2.4011
20260630 后复权收盘价 = 56.38 * 2.4011 = 135.374018

20260701 pre_close = 56.38
理论 adj_factor = 135.374018 / 56.38 = 2.4011
实际 adj_factor = 3.4848
```

判断：`20260701` 的行情 `pre_close` 未体现除权参考价变化，但复权因子从 `2.4011` 跳到 `3.4848`，更像是复权因子异常，或行情与复权因子的生效日口径不一致。

## 5. 当前结论

1. 股票和 ETF 数据质检流程已经可以跑全量，也可以用于后续每日同步后的自动检查。
2. ETF 没有 FAIL，主要剩余问题是少量成交额为 0 和复权因子覆盖率 warning。
3. 股票行情有少量 FAIL，需要优先处理 `ohlc_relationship` 和 `pct_chg_consistency`。
4. 股票复权因子整体可用，但存在 731 条后复权收益率跳变记录；问题主要集中在早期历史数据，近年则应优先人工核对。
5. `.BJ` 北交所代码已按当前策略从股票复权收益率跳变规则中忽略。
